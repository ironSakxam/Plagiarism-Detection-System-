# Plagiarism Detection System

This folder is a Raylib-based project inside the current repository.

## Build

Use the helper script:

```powershell
build.bat
```

Or in VS Code:

- `Ctrl+Shift+B` to build
- `F5` to run/debug

## Notes

- This project now includes its own copy of `raylib/src`.
- The `.vscode` config is set to use `g++` and `gdb.exe` generically.
- No Raylib setup is required again for this folder; it is self-contained.
